# Saved publisher definitions

These are archival copies of official SingStat JSON responses generated 10 October 2026, not new retrievals. Only the response body is copied; the execution wrapper `STDERR` is removed. `receipt.json` records newly computed body and original-log hashes. Exact request URL and retrieval timestamp are unknown; generation date is not substituted for retrieval time.

- [M701051 quarterly](M701051.json): updated 31 August 2026; 2014 Q4–2026 Q2.
- [M701071 annual](M701071.json): updated 29 May 2026; 2014–2025.
- Source: Monetary Authority of Singapore via SingStat Table Builder. Singapore Open Data Licence; small official metadata responses redistributed with attribution.

Both establish end-period principal/supplementary counts and rollover, billings inside/outside Singapore, and non-seasonally-adjusted status. Empty rate/write-off footnotes cannot establish averaging, annualisation mechanics or recoveries. See [data audit](../data_audit.md) for the analyst proxy and remaining unknowns.
