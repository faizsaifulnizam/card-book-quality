Method

  1. Pull — MAS credit & charge cards from data.gov.sg; structure-validated before replacing files, SHA-256 + coverage in a manifest (2014 Q4 → 2026 Q2). src/download.py
  2. Audit — units and the rate definition checked against the published annual figures before analysis (reconciles ±0.05 pt). docs/data_audit.md
  3. Stage & check — the wide raw file unpivots to one tidy row per quarter; 8 assertions fail loudly before anything is written. sql/01 · sql/05
  4. Measure & bridge — complete years only; the change in write-offs splits into volume (Δrollover × avg rate) + rate (Δrate × avg rollover), midpoint weights — exact, no residual. src/analysis.py → outputs/yearly_bridge.csv
  5. Draw, write, check — figures are code, light and dark (src/figures.py); then the decision memo and the Excel quick-check.

Reproduce

git clone https://github.com/faizsaifulnizam/card-book-quality && cd card-book-quality
uv venv .venv --python 3.12          # or: python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
uv pip install -r requirements.txt   # or: pip install -r requirements.txt

python src/download.py       # both raw CSVs → data/raw/ (gitignored)
python src/build_dataset.py  # staging + 8 checks → data/processed/quarterly.parquet
python src/analysis.py       # annual bridge + sensitivity → outputs/
python src/figures.py        # re-renders reports/figures/ (light + dark)
python src/build_workbook.py # rebuilds outputs/quick_check.xlsx

Then check outputs/yearly_bridge.csv: the 2025 row reads Δ +96.5 = volume +63.9 + rate +32.6, and the workbook's default selection (2026 Q2) shows write-offs 138.1 with a 4-quarter sum of 543.4. Data as of the 2026-10-03 pull — a later re-pull can move the newest quarters.
